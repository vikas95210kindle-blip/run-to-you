# Run to You

A little pixel running game, from Purest with love.

Play it at **https://vikas95210kindle-blip.github.io/run-to-you/**

- Solo: run through every day since 11 June 2025, catch hearts, open the letter at today.
- Five themed levels with platforms, gaps, grumpy puffs to stomp, and checkpoints.
- Play together: two phones, one room code, a direct phone-to-phone link when possible, revive each other with 3 hearts, race for the crown.

`mqtt.min.js` is the [MQTT.js](https://github.com/mqttjs/MQTT.js) 5.10.1 browser bundle (MIT), used for the live two-phone mode.
